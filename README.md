# Talk to Our AI — Voice Widget Demo

Interactive demo: a web voice widget that qualifies visitors and books a discovery call in under a minute.

Tap the mic and talk to Maya, the AI assistant for Bilal Ali's AI automation studio. She asks five quick questions (business type, missed calls, biggest pain, day, time), then books a discovery call and shows a simulated confirmation text.

**Live demo:** https://talk-to-our-ai-voice-widget-mr-bilal-alis-projects.vercel.app

**Book a real discovery call:** https://cal.com/mrbilalali/discovery-call
